# FormatFlow 1.3.1 验收记录

## 更新

自定义功能按功能 ID 独立暂存输入和处理结果，切换功能时恢复各自最近的内容。切换内置工具、重新加载功能列表或保存新功能时保留暂存；删除只清除目标功能的暂存。编辑器按功能重新建立，避免跨功能共用撤销历史。

文本仅在内存中保留，关闭应用或刷新页面后清除，不写入配置或导出文件。

## 验证

- 122 项单元测试通过。
- 6 组专项桌面测试通过：功能间切换、重新加载列表和跨工具切换、输入修改及清空、新建测试并保存、删除隔离、刷新后清除文本并保留配置。
- 原有 9 组自定义处理桌面回归通过，包括编译错误、超时取消、导入导出、全屏及缩进设置。
- 构建使用 Windows x64 便携目标，未内置 JDK。自定义 Java 功能继续要求系统 JDK 8–23。
- 最终 EXE 的启动、内置文本工具、选区、全屏和系统 Java 调用检查通过，测试启动耗时约 18.8 秒（包含便携包解压）。
