# FormatFlow 1.2 验收记录

日期：2026-09-14。实测环境：Windows 11 x64，Electron 40.10.6。

## 本版变更

- 参考 Apple Human Interface Guidelines 重构五个工具的界面：紧凑侧栏、统一标题区、工具栏、按钮、分段控件、编辑面板、表单、空状态和状态提示。
- 新增浅色、深色、跟随系统外观，默认浅色。只保存外观偏好；切换外观不重建编辑器，不丢失输入、结果和撤销记录。
- 统一语义配色，覆盖代码高亮、JSON 树、搜索面板、折叠占位符、选区及错误提示。
- 修复快捷键弹窗关闭后的焦点返回；模态期间限制焦点并阻止后台工具快捷键。
- 文本处理分类支持左右方向键、Home / End；窄分栏中的结果提示按可用高度调整。
- 保留 Windows 原生窗口操作和全部文本处理功能。

## 验证结果

- `npm test`：122 项核心与边界测试通过。
- `npm run build`：TypeScript 检查及生产构建通过。
- `npm run test:desktop`：11 组原有桌面功能检查通过。
- `npm run test:text`：6 组文本操作、鼠标/键盘选择、末行高亮和只读复制检查通过。
- `npm run test:ui`：9 组界面检查通过：
  1. 五个工具的浅色与深色布局和截图。
  2. 主题切换后输入、结果和撤销记录保留。
  3. 深色搜索面板、搜索结果和代码折叠占位符。
  4. 深色选区实际覆盖最后一行；失焦后仍有背景。
  5. 外观保存、刷新恢复、实时跟随系统、手动选择优先。
  6. 弹窗焦点约束、后台快捷键阻止、关闭后焦点返回。
  7. 文本分类的方向键与 Home / End。
  8. 940 × 640 下全部工具、分类及 30% / 75% 极端分栏；操作和空状态无越界，编辑器保留可用高度。
  9. 基础文字、辅助文字、强调色、语法色在对应常规背景上的对比度不低于 4.5:1；减少动态效果设置生效。

上述 26 组桌面检查也已对 `release/win-unpacked/FormatFlow.exe` 执行并全部通过。

ASAR 包内版本为 1.2.0；四个前端构建文件与当前 `dist` 逐字节一致。

最终单 EXE 已通过便携解压启动、包内 Worker、JSON 大整数格式化、文本压缩、选区、原生全屏与退出、浅深色切换检查。本次从启动到界面就绪约 11.7 秒，包含便携包解压。
