## 大文本

使用真实窗口、剪贴板粘贴、UI 格式化按钮。JSON 样本为重复的对象数组；SQL 样本为包含 JOIN / WHERE / ORDER BY 的多语句脚本。结果随硬件、输入结构和系统负载变化。

| 输入 | 粘贴 | 格式化至结果显示 | 50 ms UI 心跳的最大间隔 | 树 DOM 行数 |
| --- | ---: | ---: | ---: | ---: |
| JSON 1 MB | 97 ms | 313 ms | 109 ms | 100 |
| JSON 10 MB | 148 ms | 1,709 ms | 307 ms | 100 |
| SQL 1 MB | 150 ms | 2,588 ms | 83 ms | — |
| SQL 10 MB | 217 ms | 21,394 ms | 176 ms | — |

测量使用 ASCII 文本，1 MB 按 1,048,576 字节估算；最后一个完整对象/语句使输入略大于目标尺寸。UI 心跳只衡量本次处理期间事件循环间隔，不等于显示器帧率。

JSON 10 MB 的结果写入编辑器时观测到一次约 0.3 秒间隔；SQL 10 MB 计算时间较长，但整个过程中界面持续响应，支持取消。单条极大 SQL、极深嵌套与存储过程不等同于本样本，不对所有输入承诺相同耗时。
