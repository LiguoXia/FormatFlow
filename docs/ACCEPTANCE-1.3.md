## 使用条件与验证边界

自定义 Java 功能需要系统 JDK 8–23，建议安装 JDK 21；不支持 JDK 24 及以上，因为其已永久禁用当前隔离方案依赖的 SecurityManager。内置功能不需要 JDK。已实测 JDK 8；其他受支持版本和 Windows 10 未逐一实测。

该模块提供进程与 Java 权限限制，不等同于操作系统虚拟机隔离。详细使用方式见 `CUSTOM-PROCESSORS.md`，实现与安全边界见 `CUSTOM-ARCHITECTURE.md`。
