# FormatFlow 1.1 验收记录

日期：2026-09-11。实测环境：Windows 11 x64，Electron 40.10.6。

## 本版变更

1. 修复 CodeMirror 当前行的实色背景遮住选择背景的问题。选中时当前行变为透明，选区使用更清晰的蓝色；失去焦点后保留柔和高亮，底部显示已选字符数。统一用于 JSON、SQL、配置和文本编辑器。
2. 新增左侧“文本处理”导航及 Ctrl + 5 快捷键。
3. 新增 26 项文本操作，覆盖 JSON / 普通文本压缩、命名、大小写、空白清理、行去重/排序、行号以及 URL / Base64 / Unicode 编解码。
4. 左侧保留原文，右侧展示可选中复制的只读结果；支持将结果用作下一次输入，替换输入可撤销。处理在本地 Worker 中执行，输入变化会使旧结果失效。

## 验证

- `npm test`：122 项测试通过，其中 68 项新增测试涵盖文本操作及边界情况。
- JSON 压缩验证了字符串内部空格、转义、重复键、超出安全整数范围的数字和指数写法不会被重写。
- 对约 10 MB 的密集 JSON 做了压缩回归，确认不存在逐项替换整段字符串导致的性能退化。
- `npm run test:desktop`：原有 11 组真实桌面回归通过。
- `npm run test:text`：新增 6 组真实桌面验收通过：
  - Ctrl + A 覆盖最后一行字符，选区绘制矩形实际覆盖末尾字符；当前行背景为透明。
  - 失焦后保留选区，Ctrl + C 得到包含最后一行的完整原文。
  - 新导航、JSON 压缩、大整数与字符串空格保留、非法 JSON 错误提示。
  - 驼峰/下划线及大小写转换、结果串联和撤销。
  - 鼠标选择、只读结果全选复制、行去重/排序、有效空结果、中文及 Emoji 的 Base64 往返。
  - 940 × 640 下五项导航和四个文本操作分类布局，无操作按钮越出工作区。

## 使用约定

- 点击具体操作会处理左侧全部输入，选择文字主要用于复制。当前操作可通过 Ctrl + Enter 重复执行。
- “JSON 压缩”按 JSON 语法移除结构空白；“去除全部空白”会删除普通文本里的所有空格和换行，二者用途不同。
- 去重行使用精确匹配，保留首次出现顺序。行号移除支持数字加点号、右括号或顿号。
- Base64 按 UTF-8 编解码，URL 编解码用于参数值。Unicode 还原仅解码 Unicode 转义，不改写其他反斜杠序列。
