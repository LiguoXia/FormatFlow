# FormatFlow v1.2.0

面向 Windows 的本地文本处理工具箱，支持 JSON、SQL、时间戳、Properties / YAML 和 26 项常用文本操作。

## 本次更新

- 参考 Apple Human Interface Guidelines 重构五个工具的整体界面。
- 统一侧栏、标题、工具栏、按钮、表单、面板、空状态和提示。
- 新增浅色、深色、跟随系统外观，记住外观选择。
- 语法高亮、结构树、搜索框、代码折叠与选区同步适配主题。
- 改进键盘焦点、快捷键指南、文本分类导航和窄窗口布局。
- 继续保留文本选中复制、完整末行高亮及全部文本处理能力。

## 下载与运行

下载附件 `FormatFlow-1.2.0-win-x64.exe`，双击运行，无需安装 Node.js。

便携版首次启动需要解压内置运行文件。关闭应用后，输入文本不会自动保存。

`SHA256SUMS-1.2.0.txt` 提供 EXE 的 SHA-256 校验值，`ACCEPTANCE-1.2.md` 为详细验收记录。GitHub 自动生成的 Source code 压缩包用于获取源码，运行应用请下载 EXE。

- 122 项单元测试、26 组桌面回归通过。
